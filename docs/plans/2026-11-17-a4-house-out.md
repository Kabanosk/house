# A4: `house out` (minimal) — full output in a file, an envelope in context — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Long commands that may fail (full test runs, builds, training outside `house exp`) run through `house out -- <command>`: the full output goes to `.house/tmp/out/<id>.log`, the agent sees a short envelope (exit code, size, time, the last ~40 lines, a ready `house out show … --grep` command), and one reader serves both `out` logs and `house exp` logs.

**Architecture:** `houselib/outlog.py` runs the command (own process group, `PYTHONUNBUFFERED=1`), streams its output to the log with the same tail cap as `house exp` (`exp.LOG_CAP`, shared helper), builds the envelope, and reads logs with `--grep` (bounded). `cli.cmd_out` wires `house out -- CMD`, `house out show <id|E-###> --grep P`, `house out prune [--days N]`. `guard` treats `house out -- CMD` like CMD.

**Tech Stack:** Python 3.11+ stdlib, `unittest`.

**Accepted:** Wojtek, 2026-11-17 (Signal, question 9).

**Spec:** `docs/specs/2026-11-16-agno-adoptions-design.md` §10 (A4, minimal version — Wojtek 2026-11-17); order §5 step 5. Paging (`--page`) is in §17 (later).

## Global Constraints

- Stdlib only; tests run real short commands (`python3 -c …`), synthetic logs; full suite green before commit; English docstrings.
- Log path `.house/tmp/out/<id>.log` (git-ignored, no migration); contest from `HOUSE_DIR` or `guard.contest_root(cwd)`, also inside a worker worktree; id: `YYYYMMDD-HHMMSS-<4 hex>`.
- Log cap: the same limit and code as `house exp` (last `LOG_CAP` characters) — move the shared bit into one helper used by both.
- Envelope (≤ ~4 000 characters): exit code (128+n on a signal), bytes, lines, duration, last ~40 lines each cut to ~500 characters, `\r` progress lines collapsed to their last state, and the ready command `house out show <id> --grep '<pattern>'`.
- `show <id|E-###> --grep PATTERN`: literal pattern by default, max 20 hits with 2 lines of context, lines ≤500 characters, total ≤16 000 characters, a `more hits` note; `E-###` reads the experiment's log.
- `prune [--days N]` deletes `out` logs older than N days (default 7); `house exp prune` unchanged.
- Exit code of `house out -- CMD` is the command's exit code (128+n on a signal); Ctrl-C stops the command, the log keeps what was written, the envelope is still printed.
- Signal jobs block `house`, so `house out` is not available there and must not be.

## Review Focus

- A command printing one 1 MB line → the log keeps the tail, the envelope line is cut to ~500 characters.
- A progress bar with `\r` updates → one line, its last state.
- `house out -- rm -rf tests/` in a contest where `tests/` is protected → refused by the guard exactly like `rm -rf tests/`.
- Running from a worker worktree → the log goes into the main contest's `.house/tmp/out/`, `show` finds it from the worktree.
- A command that never ends → the user's Ctrl-C (SIGINT to the group) leaves a log and prints the envelope with exit 130.
